# Journal de développement, novembre 2026

## 2026-11-09

- Projet créé avec `create-next-app@16.4.5` (Next.js 16.4.5, React 19.3, TypeScript 5.9, Tailwind 4.3).
- Sources du brief vérifiées avant affichage dans l'app :
  - Lally et al. (2010) via le BPS Research Digest : 18 à 254 jours (254 = extrapolation au-delà
    des 84 jours de l'étude), moyenne 66 jours, exercice environ 1,5 fois plus long, un jour raté
    isolé a peu d'effet.
  - Roberts et al. (2017), résumé PubMed : 207 études, surtout cliniques, durée moyenne
    d'intervention de 24 semaines.
  - Hudson et al., JPSP 2019 (en ligne 2018) : seuls les défis accomplis prédisent le changement.
  - Santé publique France : 10 verres par semaine maximum, 2 par jour, des jours sans.
  - OMS (2020) : 150 à 300 minutes d'activité modérée par semaine. **Non vérifié dans cette
    session** : la fréquence « au moins 2 fois par semaine » pour le renforcement musculaire. L'app
    ne l'affiche donc pas.
  - Seuils micro 2026 (Hayot Expertise, 8 juin 2026) : 37 500 €, 41 250 €, 83 600 €.
  - 3114 (ministère de la Santé) : gratuit, confidentiel, 24 h/24 ; 15 ou 112 en cas de danger
    immédiat.
  - OWASP Top 10:2025 : liste relevée sur owasp.org.
- Logique métier pure et testée (55 tests unitaires).
- Données chiffrées par utilisateur, authentification avec TOTP obligatoire.
- Écrans MVP, PWA, saisie hors ligne, rappels push, CSP à nonce.
- 14 tests e2e Playwright, dont axe-core WCAG 2.2 A/AA en mode clair et sombre sur chaque page.
- Problèmes rencontrés : voir `docs/troubleshooting/`. Décisions : ADR 0001 à 0007.
- Non fait : CI GitHub Actions (versions des actions non vérifiables depuis la session), choix de
  l'hébergeur UE, modules V2 listés dans l'ADR 0007.

### Déploiement Cloudflare Workers (même jour)

- Adaptateur `@opennextjs/cloudflare` 1.20.16, Wrangler 4.158.0 (versions npm vérifiées).
- Passage de Postgres.js à `pg` (Postgres.js + Drizzle via Hyperdrive non supporté selon Cloudflare).
- `proxy.ts` remplacé par `middleware.ts` (Edge) : le proxy Node.js n'est pas pris en charge par
  OpenNext.
- Deux incompatibilités trouvées dans workerd et corrigées : sockets fermées avec un `Pool`
  `maxUses: 1`, et `cipher.update()` qui exige un Buffer. Voir
  `docs/troubleshooting/cloudflare-workers.md`.
- 14/14 tests e2e dans workerd et sous Node.js. Bundle : 18,3 Mio (limite 64 Mio).
- Non testés : déploiement réel, envoi push réel via `web-push`, CPU en production.

### Neon Auth étudiée, migration reportée (même jour)

- Neon Auth (Managed Better Auth, `@neon/auth` 0.8.2) ne prend pas encore en charge la MFA
  (« Coming soon » sur la feuille de route Neon). Le TOTP obligatoire de l'ADR 0003 serait perdu.
- Décision : garder Better Auth auto-hébergé. Voir ADR 0009.

### Fusion de NYX-KAIROS (même jour)

Branche : `feature/merge-nyx-kairos`. Décision : ADR 0010.

- Repris : routine par phases, entretien, consommations, santé, réseau, bilan du jour et émotions,
  revues hebdomadaire et mensuelle, objectifs et projets, manifeste, atelier, gamification
  optionnelle. 23 tables avec `user_id` et clés étrangères composites, colonnes sensibles chiffrées
  par utilisateur (`sealed()`), API JSON derrière `route()` (CSRF, TOTP, zod, `no-store`).
- Non repris : authentification NYX, pilote Neon HTTP, `proxy.ts`, import de sauvegarde (il
  effaçait toutes les tables), habitudes et tableau de bord NYX (remplacés par ceux de K et la page
  Routine).
- Script `pnpm migrate:nyx` : testé sur une base NYX de test (doublons, liens et historiques
  orphelins, piliers, habitudes en pause, badge sans source abandonné, second passage refusé).
- Vérification : `pnpm typecheck`, `pnpm lint` (0 erreur ; avertissements React Compiler dans les
  écrans NYX, comme dans NYX), 153 tests unitaires, `pnpm build`, 32 tests e2e.

#### Problèmes rencontrés

- Clés étrangères composites créées avant leurs index uniques par drizzle-kit : contraintes
  `UNIQUE` déclarées dans la table à la place (`docs/troubleshooting/outillage.md`).
- Le surveillant de notifications NYX interrogeait l'API chaque minute même alertes désactivées :
  un compte sans TOTP recevait 401 et était renvoyé vers `/connexion`. Il ne fait plus rien tant
  que les alertes ne sont pas activées.
- axe signalait un défaut de contraste pendant les animations d'apparition (éléments à moitié
  transparents). Le test attend la fin des animations ; les couleurs finales passent.
- `pnpm cf:build` : `EPERM symlink` sous Windows (mode développeur désactivé). Build Workers non
  vérifié localement.
- Port 5432 refusé par Windows pour `docker compose` : tests lancés sur un conteneur jetable
  (port 55432).

#### Non fait

- Build et e2e dans workerd (à lancer depuis WSL ou Workers Builds).
- Migration des données de production NYX (à lancer par le propriétaire, voir README).
- Couleurs NYX en jetons clair/sombre ; unification « Journée type » / « Routine ».
